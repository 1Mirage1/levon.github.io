Здесь можно хранить собственные фотографии, изображения дипломов, приветственное видео и другие медиафайлы.
Рекомендуемые названия:
- intro.mp4 — приветственное видео
- specialist.jpg — портрет специалиста
- certificate-1.jpg, certificate-2.jpg, certificate-3.jpg — дипломы

Для подключения файлов используются настройки в app.js (SITE_DATA и массив certificates).
